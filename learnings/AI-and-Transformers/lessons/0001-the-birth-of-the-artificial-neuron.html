The Birth of the Artificial Neuron

McCulloch & Pitts (1943) → The Perceptron (1958) → First AI Winter (1969)

The question that started everything

In 1943, a neurophysiologist named Warren McCulloch and a mathematician named Walter Pitts asked an audacious question: can thought be computation?

Not a metaphor. An actual engineering question. If a brain is made of neurons that fire based on their inputs, maybe you could model those neurons mathematically — and then chain them together to compute anything a brain computes.

Their 1943 paper, "A Logical Calculus of the Ideas Immanent in Nervous Activity," gave the first answer. It is the conceptual ancestor of every neural network in existence today — including whatever produced this lesson.

What a real neuron actually does

A biological neuron receives electrical signals from upstream neurons through branching fibres called dendrites. It sums those signals. If the total crosses some threshold, the neuron fires — it sends its own signal down the long fibre (axon) that connects to the next neurons.

That is the entire mechanism McCulloch and Pitts kept. They discarded timing, chemistry, feedback loops — everything except:

  1. Inputs arrive, each with some weight.
  2. Weights are summed.
  3. If the sum exceeds a threshold, the neuron fires.

This is not a realistic model of a brain. It is a logical abstraction — just enough structure to reason about computation.

The McCulloch–Pitts model

Formally, the neuron has n inputs x₁, x₂, …, xₙ — each either 0 (no signal) or 1 (signal present). Each input has a weight wᵢ that says how much that input's vote counts. The neuron computes:

z = w₁x₁ + w₂x₂ + … + wₙxₙ
output = 1  if  z ≥ θ,  else  0 The McCulloch–Pitts neuron. θ (theta) is the firing threshold.

In the compact notation you will see everywhere: z = wᵀx, where w and x are vectors (lists of numbers) and wᵀx means "multiply each pair and sum" — a dot product. Then apply the threshold.

A McCulloch–Pitts neuron. Inputs x₁…xₙ arrive with weights w₁…wₙ. The neuron fires (ŷ = 1) when the weighted sum ≥ threshold θ.

Think of it as a weighted vote. Each input casts a vote (0 or 1), weighted by how much that input matters. The neuron fires if the total vote clears the bar.

What this model can already compute

Despite its simplicity, the McCulloch–Pitts neuron can implement any basic logical operation. You just choose weights and threshold carefully: 

AND gate: w₁ = 1, w₂ = 1, θ = 2
  → fires only when both x₁ = 1 AND x₂ = 1 (sum = 2 ≥ 2)

OR gate:  w₁ = 1, w₂ = 1, θ = 1
  → fires when either x₁ = 1 OR x₂ = 1 (sum ≥ 1)

NOT gate: w₁ = −1, θ = −0.5
  → fires only when x₁ = 0 (sum = 0 ≥ −0.5); silent when x₁ = 1 (sum = −1 < −0.5)

McCulloch and Pitts proved you can chain these neurons to compute any logical formula — AND, OR, NOT, and their combinations. Since all of mathematics can be built from logical operations, this suggested that thought itself might be implementable in neurons.

Why negative weights matter The NOT gate uses a negative weight. That is an inhibitory connection — the input actively suppresses firing. Real neurons have both excitatory (positive weight) and inhibitory (negative weight) connections. The model keeps this.

The missing piece: there is no learning

There is a serious problem. The weights and threshold are set by hand for each task. A human figures out that AND needs (w₁=1, w₂=1, θ=2). That is not learning — that is programming.

A brain learns. It adjusts its connections from experience. The McCulloch–Pitts model provides a mechanism but no process.

Frank Rosenblatt, a psychologist at Cornell, fixed this in 1958.

The Perceptron: teaching the neuron to learn

Rosenblatt's Perceptron is the same weighted-vote model, but now with a learning algorithm. The key idea: if the neuron makes a mistake, nudge the weights in the direction that would have gotten it right.

Concretely, for each labelled example (x, y) — where x is the input and y ∈ {0, 1} is the correct answer:

ŷ  =  1  if  wᵀx ≥ θ,  else  0

wᵢ  ←  wᵢ  +  η(y − ŷ)xᵢ   for each input i The Perceptron learning rule. η (eta) is the learning rate — how big a step to take.

Walk through the three cases:

  • Correct prediction — (y − ŷ) = 0. Nothing changes.
  • Should have fired but didn't — y = 1, ŷ = 0, so (y − ŷ) = +1. We increase the weights of every active input (xᵢ = 1), making those inputs more likely to push the sum over threshold next time.
  • Fired when it shouldn't have — y = 0, ŷ = 1, so (y − ŷ) = −1. We decrease weights of active inputs, making them less likely to trigger a false alarm.

Repeat for all training examples, loop again, keep going until no mistakes remain. Rosenblatt proved something remarkable: if the data is linearly separable, the Perceptron is guaranteed to find a solution in a finite number of steps — the Perceptron Convergence Theorem.

Why this matters historically Every gradient-based learning algorithm in deep learning today — SGD, Adam, RMSProp — descends conceptually from this rule. The core idea ("made a mistake; adjust in the direction that corrects it") has never changed. What changed is how you compute the adjustment for deeper networks.

The press went wild. The New York Times reported that the Navy expected the Perceptron to "be able to walk, talk, see, write, reproduce itself and be conscious of its existence." The Navy funded a physical Perceptron — the Mark I — weighing 7 tonnes, with randomly wired photocells for "eyes." Rosenblatt talked about machines that would translate languages and recognise faces.

It did not go well.

Linear separability — and why XOR breaks everything

Rosenblatt's convergence guarantee came with a condition: linearly separable. This has a precise geometric meaning.

In 2D (two inputs), a Perceptron draws a decision boundary that is always a straight line. Points on one side fire (ŷ = 1); points on the other side don't (ŷ = 0). Linearly separable means: there exists some line that correctly separates the two classes.

AND is linearly separable — one line cleanly separates the single "1" point. XOR is not — the "1" outputs sit at diagonal corners; any line misclassifies at least one.

Now look at XOR. The table is: 

(x₁=0, x₂=0) → 0    (x₁=1, x₂=0) → 1
(x₁=0, x₂=1) → 1    (x₁=1, x₂=1) → 0

The class-1 outputs (filled points in the diagram) sit at opposite corners — the anti-diagonal. The class-0 outputs sit at the other two corners. No straight line can separate these groups. If you try a horizontal line, you split one column correctly but botch the other. A diagonal fares no better. Any line you draw misclassifies at least one point.

This is not a quirk of XOR specifically. It is a consequence of what a Perceptron fundamentally computes: a linear decision boundary. Change the weights, shift the threshold — you are still just rotating and translating a flat line. Non-linearly separable patterns are permanently out of reach.

The fall: Minsky & Papert (1969) and the first AI winter

Marvin Minsky and Seymour Papert, two of the leading figures at MIT's AI lab, published Perceptrons in 1969. It was a rigorous mathematical analysis of what single-layer Perceptrons could and could not compute. The XOR limitation was front and centre.

The book was technically correct. Its impact was catastrophic and arguably not entirely fair.

Minsky and Papert's proof focused on single-layer networks. They knew multi-layer networks could solve XOR — you can construct one by hand. What they argued was that there was no known efficient way to train multi-layer networks. At the time, that was true. The training algorithm that would eventually fix this — backpropagation — was not widely understood until 1986.

But the impression left in the wider research community (and funding agencies) was stronger than the actual claim: that neural networks were fundamentally limited. Funding collapsed. Researchers moved to other approaches. The field entered what is now called the first AI winter — roughly a decade in which neural networks attracted little serious investment.

A historical note worth holding: this pattern — a proof that some narrow version of a technique is limited, generalised into a claim that the whole approach is doomed — repeats in AI history. Minsky and Papert's critique of single-layer Perceptrons was conflated with a critique of neural networks in general. Keep an eye for this when you read about more recent "AI is hitting a wall" claims.

What this set up

The Perceptron failure planted two seeds for the next era. Both are worth internalising, because every major idea that follows grows from them:

Depth. A single layer of weighted decisions has a fundamental expressiveness ceiling. You need multiple layers — the output of one layer becoming the input of the next — to carve out arbitrarily complex decision boundaries. This is why every modern network is "deep."

Smooth non-linearity. The Perceptron's step function (0 or 1) is mathematically brutal. It has zero gradient almost everywhere, and an undefined gradient at the threshold. You cannot use calculus to adjust it in a principled way. The next generation of models would replace the hard step with smooth "squashing" functions — the sigmoid, later ReLU — that could be differentiated, making calculus (specifically the chain rule) the engine of learning.

Those two ideas — depth and differentiable non-linearity — are the complete recipe for backpropagation, the algorithm that would revive the field in 1986. That is Lesson 0002.

Check your understanding

Answer from memory if you can. The goal is retrieval practice, not recognition — close this lesson and try before looking back.

1. A McCulloch–Pitts neuron fires when its inputs cross a threshold. What is the exact computation that produces the value being thresholded?

Correct. z = w₁x₁ + w₂x₂ + … + wₙxₙ — a dot product of weight and input vectors. The threshold compares this sum to θ. The weighted sum is the core operation in virtually every neural network layer ever built.

2. Rosenblatt's Perceptron Convergence Theorem guarantees a solution in finite steps — but only under one condition. What is it?

Correct. "Linearly separable" means there exists a flat hyperplane (a line in 2D) that puts all class-1 examples on one side and all class-0 examples on the other. If no such hyperplane exists — as with XOR — the Perceptron will cycle forever without converging.

3. The Perceptron learning rule adjusts a weight wᵢ by the term η(y − ŷ)xᵢ. What happens to wᵢ when the neuron fires but should not have (a false alarm)?

Correct. False alarm: y = 0, ŷ = 1, so (y − ŷ) = −1. For any input xᵢ = 1 (active), wᵢ ← wᵢ + η(−1)(1) = wᵢ − η. The weight decreases, pushing the weighted sum below threshold for similar inputs next time. Only active inputs (xᵢ = 1) are adjusted — inputs that weren't involved in the mistake aren't touched.
