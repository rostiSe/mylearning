# Starting point and prior context

The user is starting the AI/Transformers track from scratch on the technical side.
They can code (so implementation examples are valid), but their math is explicitly
rusty — linear algebra, calculus, and probability need intuition rebuilt alongside
each concept. They have set up a historical arc as the learning spine (see
timeline.md) and want to trace *why* each idea appeared, not just that it did.

**Implications:** Begin at the foundations (1943 McCulloch-Pitts). Do not skip the
math, but do not assume fluency either — every new piece of notation needs a
one-sentence explanation of what it means. The historical frame (what problem this
solved / what it still couldn't do / what it set up next) should be the organising
principle of every lesson.
